# Cannaville Studio

**Cannaville Studio** is a highly disciplined, multi-agent AI game development studio designed specifically for building games in Unreal Engine 5. It leverages specialized agent personas, strict psychological principles, and rigorous workflows to deliver production-ready game components, systems, and assets efficiently.

## The 5 Orchestrators

The studio operates under the direction of 5 Orchestrators, each acting as a lead for a core discipline in game development. They delegate tasks, enforce standards, and maintain the overarching vision of the project.

1. **Tech Director** (`cannaville_tech_director`)
   - **Role:** Leads all engineering tasks, code implementation (C++/Blueprints), bug fixes, and architecture discussions.
   - **Responsibilities:** Ensures technical feasibility, oversees system architecture, and maintains code quality standards.

2. **Art Director** (`cannaville_art_director`)
   - **Role:** Oversees visuals, lighting, UI/UX, art style, and composition.
   - **Responsibilities:** Maintains visual consistency, guides asset creation, and ensures the aesthetic aligns with the game's vision.

3. **Design Lead** (`cannaville_design_lead`)
   - **Role:** Handles new game features, mechanics design, systems balancing, and narrative/lore writing.
   - **Responsibilities:** Defines how the game plays, balances core loops, and crafts the player experience.

4. **QA Lead** (`cannaville_qa_lead`)
   - **Role:** Manages code reviews, QA testing, optimization tracking, and performance checks.
   - **Responsibilities:** Ensures stability, tracks metrics, and acts as the final gatekeeper for quality before completion.

5. **Project Manager (PM)** (`cannaville_pm`)
   - **Role:** Directs project management, roadmap scheduling, scope control, and marketing strategies.
   - **Responsibilities:** Keeps the project on track, manages milestones (e.g., Steam Next Fest), and prioritizes tasks.

## Subagents

To execute specialized tasks, Orchestrators rely on a team of focused subagents:

- **Coder:** Implements logic, writes C++ code or Blueprints, and handles technical problem-solving.
- **QA Tester:** Runs tests, reproduces bugs, and verifies that features work as intended.
- **Git Master:** Manages version control, handles branching, merges, and ensures commit hygiene.
- *(Other specialized agents are spun up as needed to handle specific asset generation, documentation, or research tasks.)*

## Core Psychological Principles

Cannaville Studio operates on strict behavioral frameworks to ensure reliable, high-quality output. All agents and orchestrators are bound by these three core principles:

### 1. Verification Before Completion (VBC)
No task is considered complete until it has been rigorously verified. 
- Agents must build, test, or review their work before claiming success.
- Assumptions are never accepted; evidence (logs, successful builds, visual confirmation) is required.

### 2. Skill Discovery Optimization (SDO)
Agents are expected to proactively search for and utilize the best available skills, plugins, and tools for the job.
- Before starting a complex task, agents read relevant documentation and skill files.
- Problem-solving favors leveraging established guidelines and scripts over improvised solutions.

### 3. Authority
A strict hierarchy is enforced to prevent circular dependencies and scope creep.
- **Subagents** report to **Orchestrators**.
- **Orchestrators** enforce standards and report to the **User**.
- Directives from a higher authority (especially the User) override all other considerations.
