# Skills

This repository contains my custom AI Agent skills, orchestrators, and subagent configurations for the Antigravity ecosystem.

## Plugins
* **cannaville-studio**: A highly specialized, zero-assumption, strictly delegating agent architecture designed for Unreal Engine 5 game development. Features specialized teams for Game Design, Art Direction, Engineering, and Quality Assurance.
* **agent-architect**: Meta-agent tools for designing and deploying new agent architectures.
* **ue5-fantastic-five**: Legacy orchestration plugin.
